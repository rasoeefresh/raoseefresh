💡 Cloud Persistence Guide • Permanent Storage Architecture

Why did changes reset across sessions or devices?

Your website is hosted on Vercel as static files. When you edit rates, outlet details, or banners in this admin panel, your browser saves them to private localStorage on this computer only.

❌ Why new sessions see default values:

Customers on their phones, incognito sessions, or other devices don't have access to your computer's browser storage. They load the static default code from Vercel.

✅ How to make your changes permanent:

Use 1-Click Code Export below to download updated code files and upload them to Vercel, or connect Live Cloud Sync for real-time live updates without redeploying!

When you edit products or rates in this admin browser, changes save to your private browser storage. Vercel serves static code files to customers. To make your custom rates & outlet profile the permanent defaults for every customer worldwide, deploy your updated files to Vercel.

How to deploy to Vercel (1 Minute):

  1. Click Download Deploy ZIP above.
  2. Open your Vercel Dashboard and select your project.
